# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub: open the [Security tab](https://github.com/rsoaresdev/iuc-portugal/security) of this repository and choose **Report a vulnerability**.

Include what is affected, how to reproduce it and the impact you expect. You will get an answer within a week, and a fix or a plan within 30 days. Once a fix is released, you are credited in the release notes unless you prefer otherwise.
